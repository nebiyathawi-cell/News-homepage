# Frontend Mentor - News Homepage

My solution to the [News Homepage challenge](https://www.frontendmentor.io/challenges/news-homepage-H6SWTa1MFl) from Frontend Mentor.

## Overview

### The Challenge

Build a responsive news homepage that matches the provided design.

Users should be able to:
- View the layout on different screen sizes.
- Navigate using the navigation menu.
- See hover and focus states on interactive elements.
- Open and close the mobile navigation menu.

### Screenshot

## Built With

- HTML5
- Tailwind CSS v4
- JavaScript
- Semantic HTML
- CSS Grid
- Flexbox
- Responsive design principles

## Features

- Responsive news homepage layout.
- Featured news article with a large image.
- New articles sidebar.
- Three popular article cards.
- Mobile navigation menu.
- Hover and keyboard-focus styles.

## What I Learned

While building this project, I practiced:

- Structuring a page with semantic HTML elements.
- Using Tailwind CSS utility classes.
- Creating layouts with CSS Grid and Flexbox.
- Using responsive breakpoints to adapt layouts to different screens.
- Understanding the importance of accessible navigation.
- Improving my independent problem-solving skills.

One of my biggest goals was to build the page independently before asking for help. This helped me identify areas where I need more practice.

## Challenges I Faced

- Positioning the featured article and the New sidebar.
- Managing spacing and alignment with Tailwind CSS.
- Understanding responsive grid layouts.
- Choosing the correct utility classes.
- Making the layout work on smaller screens.

These challenges helped me understand what I need to improve in my frontend development journey.
